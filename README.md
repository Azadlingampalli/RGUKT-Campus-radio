# RGUKT Campus Radio / The News Management System

A complete PHP & MySQL based Campus Radio and News Management System specially designed for RGUKT campuses.

This platform enables students to share campus news, publish announcements, upload media content through a centralized digital system. The application includes role-based dashboards for Admins, Assistant Admins, and Students to ensure secure and efficient management of campus activities.

The system supports:
- 📰 Campus News Publishing
- 🎵 Audio Uploads
- 🖼️ Image & Video Sharing
- 👨‍💼 Admin & Student Management
- 📢 Flash News & Pinned Announcements
- 🔒 Secure Authentication System

Built using PHP, MySQL, Bootstrap, and JavaScript, this project provides a modern and scalable solution for digital campus communication inside RGUKT.
